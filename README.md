# Movie Website

## Description
- This is my movie project where I consume the TMDb API for realtime data which allows users to discover movies through a simple search or through a genre choice. There is also user authentication that allows users to have a personal movie watchlist that will always be accessible to them. These movies are provided with great details for the users' review. 
- The features such as user authentication, login management, and data storage were implemented through Firebase the tool that was used as the backend for this project.

## Tech Stack
- **Languages:** JavaScript, CSS, HTML
- **Framework:** Vue.js,
- **Technologies:** Pinia, Firebase, Axios, Postman, Vite.js, Node.js
- **API:** TMDb API

## Features
- **User Authentication:** Used firebase to ensure secure account creation
- **Movie WatchList:** As a user you can store and remove movies in your watchlist and it will always be accesible
- **Discover Movies:** Discover movies from the TMDb API through a simple search, based on specific genres or the current top rated movies
- **Movie Details:** Provides movie details such as genre, runtime, director and more for a user to review

## Try It Out!
- Have Node.js installed
- Clone the repository locally
- Install the dependencies by running `npm install`
- Run the project through `npm run dev`
